# AI Job Search Assistant

A Streamlit-based job search application that combines multiple job sources and provides local AI-assisted job matching using Ollama.

## Features

- Search jobs by title and location
- Date filtering
- Remote/non-remote filtering
- Sort job results
- Arbeitnow integration
- Bundesagentur für Arbeit integration
- LinkedIn and Indeed search through TheirStack
- Duplicate job removal
- Excel export
- Local Ollama integration
- Uses `llama3.1:8b` for local AI functionality

## Technologies

- Python
- Streamlit
- pandas
- Requests
- Ollama
- TheirStack API
- Arbeitnow API
- Bundesagentur Jobsuche API
